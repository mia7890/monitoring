# Step-by-Step Deployment Guide: Laravel Application to InfinityFree Hosting

This guide provides complete, step-by-step instructions for deploying the **HYTECH Monitoring System** Laravel application to **InfinityFree** hosting without requiring SSH or command-line access on the server.

---

## Prerequisites & Constraints on InfinityFree
- **Hosting Type**: Free Shared Hosting (VistaPanel / cPanel).
- **No SSH Access**: Composer and Artisan commands cannot be executed on the server directly. All builds and dependencies must be prepared locally before uploading.
- **Web Root**: InfinityFree uses the `htdocs` directory as the public root directory.
- **Database**: MySQL is provided (accessible via phpMyAdmin). Hostname is remote (e.g., `sqlXXX.infinityfree.com`).

---

## Phase 1: Local Preparation (On Your Computer)

Perform these steps inside your local project directory (`HYTECH/monitoring`):

### 1. Build Production Frontend Assets
Compile JavaScript and CSS bundles using Vite:
```bash
npm run build
```
*This creates the compiled production assets in `public/build/`.*

### 2. Install Production Composer Dependencies
Optimize the PHP autoloader and omit development packages:
```bash
composer install --optimize-autoloader --no-dev
```

### 3. Clear Local Laravel Caches
Ensure cached local configurations are cleared before packaging:
```bash
php artisan config:clear
php artisan cache:clear
php artisan route:clear
php artisan view:clear
```

### 4. Export Your Local Database
Export your local MySQL database to an `.sql` file:
- Using phpMyAdmin: Select database `monitoring` -> **Export** -> **Quick** -> **Go** (saves `monitoring.sql`).
- Or using MySQL CLI:
  ```bash
  mysqldump -u root monitoring > monitoring.sql
  ```

---

## Phase 2: InfinityFree Database Setup

1. Log in to your **InfinityFree Client Area** and access the **Control Panel (VistaPanel)**.
2. Under the **Databases** section, click **MySQL Databases**.
3. Create a new database named `monitoring`.
4. Note down the database details provided by InfinityFree:
   - **MySQL Hostname**: `sqlXXX.infinityfree.com` *(e.g., `sql200.epizy.com`)*
   - **Database Name**: `if0_XXXXXXXX_monitoring`
   - **MySQL Username**: `if0_XXXXXXXX`
   - **MySQL Password**: *(Your InfinityFree Account Password)*
   - **Port**: `3306`
5. Open **phpMyAdmin** from the InfinityFree Control Panel.
6. Select your new database (`if0_XXXXXXXX_monitoring`), click the **Import** tab, choose your `monitoring.sql` file, and click **Go**.

## Phase 3: Server Directory Architecture

On InfinityFree, structure your files into two directories for maximum security:

```text
/ (Root Directory on Server)
├── laravel_app/                     <-- Core application (Protected outside web root)
│   ├── app/
│   ├── bootstrap/
│   ├── config/
│   ├── database/
│   ├── resources/
│   ├── routes/
│   ├── storage/
│   ├── vendor/                      <-- Generated by composer install
│   ├── .env                         <-- Production environment file
│   └── ...
└── htdocs/                          <-- Web root (Publicly accessible)
    ├── build/                       <-- Assets generated by Vite
    ├── index.php                    <-- Front Controller (Modified paths)
    ├── .htaccess                    <-- Server Rewrite Rules
    └── favicon.ico
```

## Phase 4: Prepare Server Files

### 1. Update `public/index.php` (for `htdocs/index.php`)
When copying `public/index.php` to `htdocs/index.php`, update lines 8, 13, and 16 to point to `../laravel_app/`:

```php
<?php

use Illuminate\Http\Request;

define('LARAVEL_START', microtime(true));

// 1. Maintenance Mode Check
if (file_exists($maintenance = __DIR__.'/../laravel_app/storage/framework/maintenance.php')) {
    require $maintenance;
}

// 2. Composer Autoloader
require __DIR__.'/../laravel_app/vendor/autoload.php';

// 3. Bootstrap Laravel & Handle Request
(require_once __DIR__.'/../laravel_app/bootstrap/app.php')
    ->handleRequest(Request::capture());
```

### 2. Configure Production `.env`
Create a `.env` file inside `laravel_app/` with your InfinityFree details:

```ini
APP_NAME="HYTECH Monitoring System"
APP_ENV=production
APP_KEY=base64:w8xFmVJFQ2ypVnkUXtjpjG2tc/6v6ykcTup1ucH42b8=
APP_DEBUG=false
APP_URL=http://yourdomain.infinityfreeapp.com

LOG_CHANNEL=daily
LOG_LEVEL=error

DB_CONNECTION=mysql
DB_HOST=sqlXXX.infinityfree.com
DB_PORT=3306
DB_DATABASE=if0_XXXXXXXX_monitoring
DB_USERNAME=if0_XXXXXXXX
DB_PASSWORD=your_infinityfree_password

SESSION_DRIVER=file

MONITORING_ADMIN_EMAIL=your-email@domain.com
```

## Phase 5: Upload Files via FTP

1. Connect to InfinityFree using an FTP Client (**FileZilla** or **WinSCP**):
   - **Host**: `ftpupload.net` (or the FTP host shown in your InfinityFree dashboard)
   - **Username**: Your InfinityFree FTP Username
   - **Password**: Your InfinityFree Password
   - **Port**: `21`
2. Create a new directory named `laravel_app` at the root level (same level as `htdocs`).
3. Upload all project contents **EXCEPT** `public`, `node_modules`, and `.git` into `laravel_app/`.
4. Upload all contents of your local `public/` directory into InfinityFree's `htdocs/` directory.

---

## Phase 6: Folder Permissions & Storage Link

1. Using FileZilla / FTP, right-click and set directory permissions for the following folders inside `laravel_app/`:
   - `laravel_app/storage/` -> **775** (or **777** if required)
   - `laravel_app/bootstrap/cache/` -> **775** (or **777**)
2. **Storage Public Assets**:
   If your app uses uploaded files, copy the contents of `laravel_app/storage/app/public/` into `htdocs/storage/`.

---

## Phase 7: Post-Deployment Verification

1. Check your PHP version in InfinityFree Control Panel (**Alter PHP Version**):
   - Set PHP version to **8.2** or **8.3**.
2. Open your InfinityFree domain (`http://yourdomain.infinityfreeapp.com`) in your browser.
3. Test key functionality:
   - Homepage loading.
   - User authentication / FAE login.
   - Database operations (appointments, tasks, events).

## Troubleshooting Common InfinityFree Issues

| Issue / Error | Cause | Solution |
| :--- | :--- | :--- |
| **500 Internal Server Error** | Missing `.env`, syntax error in `index.php`, or missing `vendor/`. | Check `laravel_app/storage/logs/laravel.log` and verify paths in `htdocs/index.php`. |
| **403 Forbidden** | `htdocs/index.php` missing or file permissions incorrect. | Ensure `index.php` exists inside `htdocs/` and permissions are set to `644`. |
| **Database Connection Refused** | Incorrect `DB_HOST`, `DB_DATABASE`, or `DB_USERNAME`. | Double-check MySQL credentials in InfinityFree MySQL Databases panel. Host MUST NOT be `localhost`. |
| **Styles / JS Not Loading (404)** | Missing Vite assets in `htdocs/build`. | Run `npm run build` locally and upload the generated `public/build` directory to `htdocs/build`. |
